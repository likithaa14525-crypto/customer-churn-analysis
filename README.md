# Customer Churn Analysis (Excel Project)

## Overview

This is a beginner-level data analytics project where I analyzed customer data to understand why customers are leaving (churn).

The project was done using Microsoft Excel by performing data cleaning and creating pivot tables for analysis.

## Tools Used

* Microsoft Excel
* Pivot Tables

## Steps Performed

* Cleaned the dataset by removing unnecessary columns and handling missing values
* Selected important features for analysis
* Created Pivot Tables to analyze customer churn patterns
* Derived insights based on the analysis

## Analysis

### 1. Contract vs Churn

* Compared different contract types with churn
* Found that month-to-month customers churn more

### 2. Senior Citizen vs Churn

* Compared churn behavior between senior and non-senior customers
* Observed variation in churn patterns

## Key Insights

* Customers with month-to-month contracts have higher churn
* Long-term contracts (1 year and 2 year) help in retaining customers
* Customer type (like senior citizens) can influence churn behavior
